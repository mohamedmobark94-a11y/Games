# ألعاب ترتيل القرآن · Tarteel Al-Quran Games

موقع ثابت (GitHub Pages) فيه ألعاب تفاعلية لتعليم القرآن والتجويد والعربي لغير الناطقين بالعربية.
الرابط: https://mohamedmobark94-a11y.github.io/Games/

## الملفات
- `about.html` — «عن المعلم والحجز»: حصة تجريبية مجانية، والحجز على واتساب (الرقم في `SITE.contact.whatsapp` داخل `games.js`).
- `index.html` — الصفحة الرئيسية (بحث + تصفية بالعمر والمادة + أحدث لعبة + كتاب الأسبوع). لا تحتاج تعديل عند إضافة لعبة.
- `games.js` — **قائمة الألعاب** (`window.GAMES`) و«كتاب الأسبوع» (`window.SITE.bookOfWeek`). أي لعبة جديدة = سطر هنا.
- `lessons/` — دروس عامة بدون أسماء طلاب (`window.LESSONS` في `games.js`، تظهر في تبويب «📘 الدروس»).
- `games/` — ملف HTML واحد لكل لعبة (كامل بدون أي ملفات خارجية غير خطوط Google).
- `tq-nav.js` — شريط التنقل الثابت في أعلى كل لعبة ودرس: 🏠 الرئيسية · ← رجوع · ▶ التالية · 🌐 اللغة. اللغة محفوظة في `localStorage` باسم `tq-lang` وتُشارَك مع الصفحة الرئيسية.
- `tq-i18n.css` / `tq-i18n.js` — أدوات الترجمة المشتركة (انظر «الترجمة» بالأسفل).
- `tools/add-home-button.py` — يضيف شريط التنقل لأي لعبة جديدة (آمن إن تكرر تشغيله).

## إضافة لعبة جديدة (كل يوم)
1. ضع الملف في `games/<اسم-قصير>.html` (لو الملف بدون `<!doctype html>` أضف له رأس صفحة كامل: `meta charset` و`viewport`).
2. شغّل `python3 tools/add-home-button.py` (وللدروس: `python3 tools/add-home-button.py lessons`).
3. أضف سطرًا في **أول** `window.GAMES` داخل `games.js`:
   ```js
   {file:'اسم.html', date:'YYYY-MM-DD', ico:'🎮', ar:'الاسم', en:'Name', age:['kids'|'teens'|'adults'], subj:'tajweed'|'hifz'|'arabic'|'islamic', desc:'…', book:'الكتاب (الصفحات)'},
   ```
4. لو بدأ كتاب أسبوع جديد حدّث `SITE.bookOfWeek`.
5. Commit + push على `main` → GitHub Pages ينشر خلال دقيقة.

## الترجمة (عربي / English)
- الصفحتان الرئيسيتان (`index.html` و`about.html`) ثنائيتا اللغة بالكامل. وصف الألعاب بالإنجليزية في `window.DESC_EN` آخر `games.js` (المفتاح = اسم الملف).
- داخل اللعبة: `TQI.U('عربي','English')` يعطي نصًّا مزدوجًا، و`TQI.tr('English')` سطر ترجمة تحت اقتباس عربي، و`TQI.R('الفاتحة: ٤')` يكتب المرجع «Al-Fatihah 1:4» بالإنجليزية. للـ`<option>` استخدم `data-en`.
- الصفحة المترجمة بالكامل تضيف `class="tq-i18n"` على `<body>` فتنقلب لاتجاه يسار-يمين في وضع الإنجليزية. الصفحات الأخرى تحتفظ بتخطيطها العربي ريثما تُترجم.
- المصطلحات والآيات تبقى عربية في الوضعين، والتعليمات والأسئلة والتغذية الراجعة تتبدّل. اقتباسات الكتب تبقى بنصّها العربي مع ترجمتها تحتها.
- كل الألعاب الـ16 وكل الدروس الـ9 تعمل بالعربية والإنجليزية (الأسئلة، التغذية الراجعة، الاقتباسات مع ترجمتها). دروس المحطات (`ahkam-almadd`, `ghadd-albasar`) تحمل نصها الإنجليزي في `LESSON_EN`، وعروض الشرائح (`aynuk-amana`) تستعمل قاموسًا في آخر السكربت عبر `TQI.dict({...})` (القيمة التي تبدأ بـ«§» تُبقي الآية بالعربية وتضيف ترجمتها تحتها).

## منصة المعلم (`app/`)
- `app/index.html` — لوحة المعلم (دخول بإيميل وباسورد): التسليمات، واجب/اختبار جديد، الواجبات، الطلاب.
- `app/hw.html?t=<token>` — صفحة الواجب للطالب (لينك خاص لكل طالب، من غير تسجيل دخول): أسئلة اختيارات + تسميع بالصوت، والنتيجة والتسجيل يوصلوا للمعلم.
- تابات لوحة المعلم كمان: 📚 الدروس (مكتبة دروس كل الطلاب من المولّد)، 🗂️ الخطط (خطة-الدروس.md وسجل-الدروس.md لكل طالب، منسوخة من OneDrive وتتعدّل من الموقع)، 📖 المصحف (مصحح الواضح؛ الصفحات في bucket خاص `mushaf`، للمعلم فقط)، 🎮 الألعاب (نفس قائمة `games.js`).
- `app/student.html?k=<portal_token>` — صفحة الطالب وولي الأمر: الواجبات والدرجات وآخر تقرير والدروس (دالة `get_portal`، من غير الخطط أو ملاحظات المعلم).
- `app/mushaf/` — نسخة الويب من مصحح الإضافة (`web.js` يجيب لينكات الصفحات الموقّعة ويحفظ التصحيحات في `docs/corrections`).
- البيانات في Supabase (مشروع `tarteel`)، والحماية بـ Row Level Security: لا أسماء طلاب ولا بيانات في الريبو نفسه. المفتاح في `app/config.js` مفتاح عام (publishable).

## أدوات الحلقة (من غير دخول)
- `teacher.html`: كل الدروس والألعاب مجمّعة بالتخصص مع «افتح» و«تبويب جديد» و«انسخ الرابط»، مع لعبة تسلية عشوائية ومؤقت للحلقة. التخصصات معرّفة مرة واحدة في `games.js` (`window.SUBJECTS`) وتستعملها الرئيسية واللوحة.
- الواجبات والنتائج والتقارير في **منصة المعلم** (`app/`، بدخول وSupabase) — هذه الصفحة للأدوات السريعة فقط.
- في كل لعبة ودرس: زر «أدوات الحلقة» في الشريط العلوي، وزر عائم «الموقع / المعلم» يظهر تلقائيًا في ملء الشاشة أو إذا اختفى الشريط.
- **واجب القرآن (🎧 استماع + تسميع):** في «واجب جديد» ← «🎧 واجب قرآن»: اختر السورة ومن/إلى آية والتكرار (×1…×10) والقارئ؛ الطالب يسمع المقطع آية بآية مع تظليل الآية الحالية، ثم يسمّع ويسجّل صوته. لا يُخزَّن نص قرآني في الريبو ولا قاعدة البيانات: النص من واجهة quran.com والصوت من everyayah.com يُحمَّلان في متصفح الطالب (`app/quran-data.js`). يظهر في التسليمات: عدد التكرارات التي أنهاها + تسجيله. لينك الطالب الثابت: `app/student.html?k=…` (تبويب الطلاب) وفيه زر «ابدأ واجبك الحالي».
- **لينك الطالب عند كل درس جديد:** لوحة المعلم (`app/`) تراقب جدول الدروس كل دقيقة وعند الرجوع للتبويب؛ لو ظهر درس جديد لطالب (بعد أول تشغيل) يظهر شريط «🔔 دروس جديدة» لكل طالب بزر «📲 ابعت على واتساب» (رسالة جاهزة بلغة الطالب فيها اسم الدرس ولينك صفحته الثابتة) وزر «✓ اتبعت». يُحفظ وقت آخر إرسال ورقم واتساب كل طالب في جدول `kv`. الإرسال الفعلي بضغطة منك: المواقع لا ترسل واتساب تلقائيًا.
